# 🥞 Creperia Caiçara

Landing page desenvolvida para a **Creperia Caiçara**, com o objetivo de apresentar a marca, o cardápio, os produtos e os locais de atendimento.

🌐 **[Acessar o projeto](https://creperia-caicara.vercel.app/)**

## ✨ Funcionalidades

- 📋 Cardápio com crepes doces e salgados
- 🥞 Detalhes dos produtos através de modal
- 📍 Localização dos pontos de atendimento
- 🗺️ Integração com Google Maps
- 📸 Integração com Instagram
- 🎥 Vídeo mostrando o processo de produção
- 📱 Layout responsivo para celular, tablet e desktop
- ♿ Recursos básicos de acessibilidade

## 🛠️ Tecnologias

- **React** — construção da interface e componentes
- **Vite** — desenvolvimento e build do projeto
- **JavaScript** — lógica e interações
- **CSS** — estilização, animações e responsividade
- **Lucide React** — ícones
- **Google Maps** — localização dos pontos de atendimento
- **Vercel** — deploy da aplicação

## 📚 O que foi praticado

Este projeto foi desenvolvido para praticar conceitos de desenvolvimento Front-end, como:

- Componentização com React
- Hooks (`useState`, `useEffect` e `useRef`)
- Props e renderização de listas
- Responsividade
- Animações em CSS
- Acessibilidade
- Integração com serviços externos
- Deploy de aplicações web
